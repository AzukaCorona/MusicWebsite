Hosting on GitHub Pages

Because this app is contained in a single standalone index.html file, publishing it for free on GitHub Pages takes under 2 minutes:

  1. Create a new public repository on GitHub (e.g. piano-sight-reading).
  2. Save this code into a file named index.html and push it to your repository's main branch.
  3. Go to your repository on GitHub → Settings → Pages.
  4. Under Build and deployment, select branch main (root / (root)), then click Save.
  5. Your website will be live in 60 seconds at https://<your-username>.github.io/<repo-name>/!
